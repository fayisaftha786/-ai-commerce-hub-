    Official marketplace programme & API access

    These are the legitimate routes for product data and affiliate access. None is connected to this app yet. API credentials must stay on a private server; never paste them into this page, browser storage, or a public GitHub repository.

    Amazon India · Creators API

    App status: Not connected — server integration and approved credentials required.

    Join Amazon Associates for India, qualify for API access (the current guide requires at least 10 qualifying sales in the past 30 days), register a Creators API credential, then use its OAuth 2.0 token flow. Amazon's old PA-API 5.0 has been deprecated; new work should use Creators API.

    Creators API guide · Authentication & request setup · Associates India

    Flipkart · Affiliate API

    App status: Not connected — affiliate registration and private API token required.

    Registered affiliates can use product search/details, offer and report APIs. Keyword search returns up to 10 products per request and the published API limit is 20 calls per second per affiliate. The API token must be sent as a server-side request header.

    Join Flipkart Affiliate · Token setup · Product API reference

    Meesho · Creator Program

    App status: Not connected — use the official creator portal for product selection, affiliate links and account performance.

    Meesho's creator programme is available through its creator portal. This app does not sign in to the portal or read private creator metrics. Use only an API or export that Meesho explicitly enables for your account; do not use private endpoints or scrape logged-in pages.

    Meesho Creator Program · Meesho terms & policies

    GitHub Pages hosts this app as a static site and cannot safely hold marketplace API secrets. A private backend deployment is required before live product data can be fetched. Until then, marketplace search links and user-supplied CSV files remain the supported workflow.

    4. Import real catalogue / affiliate performance data

    For the strongest ranking, export a CSV from a dashboard you are authorised to access. This tool does not connect to or scrape Meesho. Import stays in this browser; it is not uploaded.

    Recommended columns: name, platform, url, price, commission, rating, reviews, clicks, orders, returns, period_days, stock, source, checked_at. Minimum syntax requirement: name, price. For a product to qualify for “Shortlist for a small test”, also provide a valid HTTPS product/approved affiliate link, a positive confirmed commission rate, source (where you checked the product/data), and checked_at (YYYY-MM-DD). Evidence older than 7 days, missing, invalid or future-dated cannot pass the shortlist gate. If the dashboard has no CSV export, fill the template manually using only facts you can verify. Use the same reporting period for every product.

    Orders and clicks are useful only when their time window and definitions are comparable. If the file contains only product ratings, the app labels the result as catalogue quality—not evidence that people are buying.

    7. Campaign Registry

    Save a record for each post or video you plan to publish. Each record gets a campaign ID so you can keep your creative tests organised and match it to an authorised affiliate report if the programme supports campaign/sub IDs.

    Important: this registry does not track external clicks, orders or commission. Saving a campaign or exporting its ID does not attach tracking to an affiliate link. Only use programme-approved tracking/sub-ID fields and compare actual results from an authorised report.

    8. Campaign Performance Report

    Import a CSV exported from an affiliate dashboard you are authorised to access. The report is processed in this browser and is matched only by an exact campaign/sub-ID already saved in this workspace.

    Required columns: campaign_id, period_start, period_end, clicks, orders. Optional: commission, returns. Dates must be YYYY-MM-DD. If the affiliate programme does not export the campaign/sub-ID you used, attribution is unavailable; this tool will not guess which campaign caused a sale.

    Use the same reporting period and metric definitions when comparing campaigns. Report totals are supplied by your source, not independently verified. This import does not prove commission has been approved or paid.

    Choose media to preview it on this device. Files are not uploaded to this app.

    Social Media Analytics

    Enter numbers from the platform's official insights for one post and one consistent reporting period.

    Engagement rate uses (likes + comments + shares/saves) ÷ reach. Click-through rate uses clicks ÷ reach. Order rate uses attributed orders ÷ clicks. These calculations are only as reliable as the figures you enter; orders require platform/affiliate attribution.
