3. Import real catalogue / affiliate performance data

For the strongest ranking, export a CSV from a dashboard you are authorised to access. This tool does not connect to or scrape Meesho. Import stays in this browser; it is not uploaded.

Recommended columns: name, platform, url, price, commission, rating, reviews, clicks, orders, returns, period_days, stock. Minimum required columns: name, price. Orders and clicks are useful only when their time window and definitions are comparable. If the file contains only product ratings, the app labels the result as catalogue quality—not evidence that people are buying.
