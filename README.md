
# AI Commerce Hub

A low-cost product research and affiliate content workspace.

## Current features

- Product entry for Amazon, Flipkart and Meesho
- Basic product URL validation module
- Content draft generator
- Node.js automated tests
- GitHub Actions CI workflow

## Requirements

- Node.js 24 or compatible modern Node.js
- npm

## Run checks

```bash
npm run check
npm test
```

## Important limitations

This is an early prototype. Product data is not permanently stored.
The click counter is local UI activity, not verified affiliate analytics.
Live product feeds, commission data, AI APIs and social publishing
are not connected yet.

Use affiliate links only after approval by the relevant program.
Follow platform rules and clearly disclose affiliate relationships.
Never commit API keys, access tokens or passwords.
